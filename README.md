# C# Text RPG

A small console-based RPG built in C# as a learning project.

This project was created to practice C# fundamentals and object-oriented programming while building a simple, functional game.

## Features

* Character creation
* Exploration and branching paths
* Random encounters
* Turn-based combat
* Multiple enemy types
* Player health system
* Enemy health system
* Inventory system
* Potion system
* Potion healing with maximum health limits
* Input validation
* Death/game-over handling

## Technologies

* C#
* .NET
* Visual Studio

## What I Practiced

Through this project, I practiced:

* Classes and objects
* Methods
* Properties
* Lists
* Loops
* Conditional statements
* Switch statements
* Random number generation
* User input and validation
* Basic object-oriented programming
* Organizing code into separate classes
